# 基础连通性检测

手动节点的「基础连通性检测」由 Cloudflare Worker 尝试建立到节点 TCP 端口的连接。成功显示 `TCP … ms`，这是 **Worker 至节点端口的建连耗时**，不包含 DNS 查询，不是本地延迟或穿节点 HTTP 延迟。端口开放不证明代理认证、转发、出口 IP 或解锁能力。完整节点检测入口继续使用所选检测器完成这些任务。

新增或修改节点后先保存，再点击检测。基础检测不会自动保存配置，也不会发送节点密码、UUID、Cookie 或 HTTP 请求到节点。批量检测每次最多处理 60 个已启用节点，优先未检测项，浏览器并发最多 3 个；查看每个结果后可稍后继续。结果只保留在当前页面，编辑节点地址会清除对应结果，刷新页面后重新检测。

## 结果含义

| 页面状态              | 含义                                                     |
| --------------------- | -------------------------------------------------------- |
| TCP … ms              | 本次 Worker TCP 建连成功；没有进行代理协议或 TLS 验证    |
| 未建连                | 本次连接失败，不能据此断言节点不可用                     |
| 连接超时              | 本次检测达到总计 5 秒的时限                              |
| DNS 未确定            | 未能得到完整、安全的双栈解析结果，未连接                 |
| 地址受限              | 本地、私网、保留地址或不安全的解析结果，未连接           |
| 平台受限              | Cloudflare 限制的目的地址、环路或端口                    |
| UDP 不适用            | UDP 节点或 UDP 传输无法用 TCP 建连代表，使用完整节点检测 |
| 请先保存 / 请稍后重试 | 节点未保存或不存在，或达到资源保护上限                   |

域名具有多个地址时，检查 A 与 AAAA 回答内的全部 IP 和 CNAME 安全性，再选择一个 IP 进行本次连接。任一地址不安全、任一家族解析失败或响应截断，整次解析均失败。选中 IP 直接传给 socket，避免 DNS 检查后再次解析导致重绑定。没有自动重试、地址轮询、HTTP 回退或 TCP 数据写入。此单地址、单地点结果不能覆盖所有网络路径。

## API 与保护范围

`POST /api/nodes/connectivity` 使用现有管理员会话和精确同源 `Origin` 校验，JSON 请求体上限 256 字节，唯一字段是 `nodeId`（1–128 个字母、数字、下划线或连字符）。请求不接受 URL、host、port、凭据或未保存节点快照。服务端从现有业务存储读取手动节点，并仅将解析后的地址和端口交给网络调用；无需检测器数据库或新增资源。

```json
{ "nodeId": "saved-node-id" }
```

成功处理的请求返回 `success: true` 和 `data`。`data` 包含 `version: 1`、`status`、`code`、`latencyMs`、`checkedAt`（Unix 毫秒）、`measurement: "worker_tcp_connect"`、`vantage: "cloudflare_worker"`。只有 `status: "ok" / code: "port_reachable"` 含非空建连时间；未执行或未确定状态不附加假延迟。响应不包含节点链接、解析地址、密码或原始错误，不缓存，不保存到检测历史。

未登录返回 401；同源校验失败返回 403；不支持的方法返回 405；非法字段返回 400；请求过大返回 413；缺少 JSON Content-Type 返回 415；节点不存在返回 404；频率或并发保护返回 429 和 `Retry-After`。

保护限制为**每个 Worker isolate** 最多 3 个同时处理的请求、每分钟 60 次尝试、同节点 10 秒冷却，包含请求读取、存储、DNS 与连接的总时限为 5 秒。它们用于限制单实例资源，**不是整个部署的全局配额**；跨实例仍依赖管理员身份边界。每次连接完成、失败或取消均调用 socket `close()`，关闭可读和可写流，不读取服务端数据。IPv4 特殊用途范围、IPv6 非全局单播、映射地址和转换范围采用保守拒绝策略。

域名解析使用固定的 Cloudflare DNS-over-HTTPS JSON 接口，请求只包含域名和 A/AAAA 类型，不携带站点 Cookie 或节点凭据，每个响应最多 16 KiB / 32 条回答，禁止重定向。该查询会将节点域名交给 Cloudflare DNS；点击检测即发起此查询。IP 字面量不进行 DNS 查询。

## 平台与验收边界

依据 [Cloudflare TCP sockets 官方文档](https://developers.cloudflare.com/workers/runtime-apis/tcp-sockets/)，`opened` 表示连接建立，`close()` 关闭双向流；平台禁止连接 Cloudflare IP、私网、回环和端口 25。运行位置和平台限制可能使本地可用的节点在基础检测中无法连接。

默认验收使用模拟 DNS、socket 和浏览器 API，覆盖鉴权、私网混合答案、重绑定防护、超时取消、并发、限流与脱敏。构建成功和离线通过不能替代 Cloudflare 实网验证；受控公开目标的部署验证应单独记录。真实节点、设备或凭据测试继续由用户明确授权。没有引用或移植任何私有代理实现。

完整服务解锁检测初始仅选择 OpenAI 和 Claude。Netflix、YouTube、Gemini、Disney、Spotify 和 TikTok 仍可手动选择；切换任务类型或关闭后重新打开面板不会覆盖本次页面会话中的选择。选择服务本身不会发起检测，提交仍需既有明确授权。
