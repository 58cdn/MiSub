# 订阅集合读取与保存前校验

关联 [Issue #33](https://github.com/58cdn/MiSub/issues/33)。本草稿定义读取失败时停止保存的实现与验收边界。

- 权威集合读取区分不存在、查询失败和非法数据，失败不作为空集合返回。
- 订阅与订阅组全部读取、验证成功后，保存才进入通知和业务写入。
- 合法空集合和旧 D1 main 数组继续兼容；读取不创建表、不迁移存储。
- 缺失存储绑定不能报告保存成功。

验收覆盖 KV 读改写错误、D1 查询和 JSON 失败、两集合读取屏障、无绑定及旧格式。真实存储调用由合成 KV/内存 SQLite 替代。

此项不提供跨请求 CAS，也不保证写入中途失败的事务回滚。并发协议及旧格式迁移分别设计。生产数据操作、部署与迁移保持冻结。
