# 订阅集合读取与保存前校验

关联 [Issue #33](https://github.com/58cdn/MiSub/issues/33) 和 [PR #41](https://github.com/58cdn/MiSub/pull/41)。订阅或订阅组读取失败时，管理接口返回明确失败，保存停止在通知和业务写入之前。

## 集合读取约定

| 情况       | KV                              | D1                                         |
| ---------- | ------------------------------- | ------------------------------------------ |
| 合法空数据 | 键不存在或 JSON 空数组          | 查询成功且结果为空                         |
| 记录格式   | 对象数组；每项有非空字符串 `id` | 每行 JSON 对象，兼容旧 `main` 行的对象数组 |
| 非法数据   | 非法 JSON、非数组、非法条目     | 非法查询结果、非法 JSON、非法条目          |
| 存储故障   | 获取键异常即失败                | 查询异常或表不存在即失败                   |

集合读取失败统一抛出 `STORAGE_COLLECTION_READ_FAILED`，不携带原始数据或底层异常。KV 的集合 `get()` 和读取后修改接口使用同一严格校验；缺失键的通用 `get()` 仍返回 `null`，集合 getter 将合法缺失转换为空数组。非集合设置读取保留既有回退策略。

D1 的集合 getter 保留 30 秒缓存以服务普通读取；调用 `getAllSubscriptions({ authoritative: true })` 或 `getAllProfiles({ authoritative: true })` 会清除对应缓存并重新查询。失败结果不会成为缓存中的空成功，下次读取可直接重试。严格读取不建表、不执行迁移。旧数组和行记录并存时仍沿用按 ID 去重、按 `sortIndex` 排序的读取规则。

## 管理读取与保存

`handleDataRequest` 和 `handleMisubsSave` 在选定存储类型后检查相应绑定。选定 D1 而缺少 D1 绑定时，即使存在 KV 也返回 `STORAGE_UNAVAILABLE`；反向同理。已选中 D1 的集合查询失败也不会切换为 KV 成功。此处不改变 SettingsCache 的类型选择与设置读取策略，因此不代表所有配置选择问题均已解决。

两个管理接口都使用权威集合读取。全量保存与差异保存均须完成订阅、订阅组两份集合的读取与校验，才能生成后续通知和业务写入。全量行级同步复用预检快照，不在某个集合已经开始写入时再次读取另一个集合。

保存请求先校验全量条目、差异中的 `added`/`updated` 条目及 `removed` ID，并在规范化后校验最终入库集合。条目必须是含非空字符串 `id` 的对象；全量集合、各差异新增／更新数组及最终入库集合内的 ID 必须唯一；删除 ID 必须是非空字符串数组。非法请求返回 HTTP `400` 和 `INVALID_SUBSCRIPTION_DATA`，不会触发通知或业务写入。此唯一性校验仅用于保存，旧存储集合的读取兼容与 D1 去重规则保持不变。旧客户端的空数组差异仍作为合法的无操作请求。

读取失败返回 HTTP `503`、`success: false` 和稳定错误码，不返回空的成功数据或底层存储异常。写入失败返回脱敏的 HTTP `500`。绑定缺失也不能报告保存成功。

成功的 `/data` 请求仍可能触发既有的订阅组 ID 持久化与惰性计划任务；不能把这一 API 的 GET 当作只读接口。失败路径在这些动作前退出。

## 验收与限制

离线回归使用合成 KV 和本机内存 SQLite，拦截通知、缓存清理与计划任务，并禁止外部 `fetch`。覆盖双向延迟读取屏障、非法数据、查询失败、缺失表、绑定选择、缓存旁路、恢复重试、合法空数据及旧格式读取。失败路径验证零通知、零业务写入、零建表，且响应与集合读取日志不包含原始异常内容。

本项不提供跨请求 CAS，不拒绝客户端旧快照，不保证两个集合写入失败时的事务回滚，也不解决 Cron 旧快照覆盖或旧 D1 `main` 行的写入迁移问题。通知及写入仅在读取校验成功后开始；写入阶段仍可能部分成功。相关并发协议及迁移应覆盖全部写入入口后单独验收。生产数据操作、部署与迁移保持冻结。
