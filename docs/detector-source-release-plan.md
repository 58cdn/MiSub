# 检测器源码构建发行方案

MiSub Probe 的独立版本采用固定源码、依赖源码和官方 Go 工具链构建嵌入式内核，再构建五个平台的检测器。源码包、构建配方、逐实际链接文件的完整许可映射、双构建摘要和 GitHub 托管构建来源证明共同构成发行输入。

PR 和 main 的持续集成执行原生构建及离线、回环测试。发布只接受 main 的显式手动请求，在真实材料门槛全部通过后创建新版本；既有标签和发行资产保持原样。缺少或不一致的来源、许可、摘要及来源证明会阻止发行。

新版本提供原始可执行文件、固定版本的安装脚本、源码材料和校验文件。站点的安装目录须在核实实际发布资产后独立更新；未经发行的构建不能启用用户安装入口。

发行工作不创建生产检测身份、不安装或启动真实设备服务，也不探测用户节点。真实设备安装和实网验收与 CI、Pages 部署、发行成功分别记录。Issue #7 保持打开，直到对应用户验收完成。
