# 一次复制的检测器安装入口

设置页仅对经过发行目录校验的版本显示完整安装命令。用户在目标设备终端粘贴后，入口识别操作系统和原生架构，下载固定发行资产，核对大小、SHA256 与客户端能力，再进行网页批准、私密配置保存、用户安装及显式启动。

当前目录对应 [MiSub Probe 0.2.0](https://github.com/58cdn/MiSub/releases/tag/probe-v0.2.0)，发行日期 2026-10-13，源码提交 `9ccee76c3cab149f34dca96c304310c9574c0d29`。站点仅在核实该版本的真实公开资产后提供命令；未就绪、读取失败或平台缺项时保持不可用。

Linux/macOS 使用 Bash，引导器下载并验证固定版本的安装脚本。Windows x64 使用可展开审阅的 PowerShell 命令，下载并验证原始 EXE 后调用原生 `--setup`；执行策略与系统安全设置保持原样。命令不依赖当前目录已有文件或另装语言运行时。

配置存在时拒绝重新配对。恢复入口只读取并验证现有私密配置，要求已有安装的版本、配置路径与可执行文件摘要匹配，随后启动并核对真实进程状态。用户须在网页核对站点、短码和会话指纹后批准；安装完成不等于已与服务器通信，首次心跳单独显示。

仓库默认验证使用合成元数据、下载 mock、临时目录和服务 fixture。公开发行资产的核验与实际设备验收分别记录：发行可下载不代表设备已安装，安装成功不代表服务器已收到通信，首次通信也不代表真实节点检测成功。设备配对、持久身份及节点测试由用户另行明确执行。

## 平台与恢复

支持 Linux 内核 3.2 或更新版本的 amd64/arm64、macOS 13 或更新版本的 Intel/Apple Silicon，以及 Windows 10 / Server 2016 或更新版本的 x64。使用普通用户终端；Linux 需系统 CA、Bash 和可用的用户 systemd 会话，macOS 需 Bash 与当前用户的 GUI/launchd 会话，Windows 需 PowerShell 5.1 或更新版本。系统 CA 用于正常 TLS 验证，缺少可信根会失败。组织策略阻止执行时明确退出，不自动修改策略。Windows ARM64 不在本发行目标内。

下载使用固定 HTTPS 地址，限定重定向目的地、时间、次数与文件大小。发行目录中的脚本和二进制摘要都必须匹配。源码内的脚本模板没有可执行的发行元数据，直接运行会停止；实际命令只在核验发行后提供。

安装未能完成时保留已保存配置。页面的恢复命令不含配对窗口、站点或新身份请求，下载相同发行版本后只校验、恢复安装和启动。若提示版本或摘要冲突，先查看现有安装，不删除配置或重复领取身份。`--pair` 单独执行仍只保存配置；默认 Windows 命令的 `--setup` 明确包含安装和启动。

本功能不启用登录自动启动。Mac/Linux 使用既有用户服务管理器，Windows 在当前登录会话启动托管进程；重装或卸载继续要求先停止。首次服务器通信在网页另行确认。
