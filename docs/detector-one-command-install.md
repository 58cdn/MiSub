# 一次复制的检测器安装入口

设置页仅对经过发行目录校验的版本显示完整安装命令。用户在目标设备终端粘贴后，入口识别操作系统和原生架构，下载固定发行资产，核对大小、SHA256 与客户端能力，再进行网页批准、私密配置保存、用户安装及显式启动。

Linux/macOS 使用 Bash，引导器下载并验证固定版本的安装脚本。Windows x64 使用可展开审阅的 PowerShell 命令，下载并验证原始 EXE 后调用原生 `--setup`；执行策略与系统安全设置保持原样。命令不依赖当前目录已有文件或另装语言运行时。

配置存在时拒绝重新配对。恢复入口只读取并验证现有私密配置，要求已有安装的版本、配置路径与可执行文件摘要匹配，随后启动并核对真实进程状态。用户须在网页核对站点、短码和会话指纹后批准；安装完成不等于已与服务器通信，首次心跳单独显示。

默认验证使用合成发行元数据、下载 mock、临时目录和服务后端 fixture。真实下载资产在新版本公开后核验；实际设备安装、持久身份与节点测试由用户另行明确执行。生产目录未就绪时入口保持不可用。
