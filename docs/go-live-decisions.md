## 只读访问

| 对象             | 当前证据                                          | 下一步                                                                              |
| ---------------- | ------------------------------------------------- | ----------------------------------------------------------------------------------- |
| GitHub           | 仓库、PR、CI 元数据及制品可读                     | 核对源码 SHA、合并树和实际门槛摘要                                                  |
| Cloudflare       | 既有 Pages 自动部署保护成功；人工浏览器会话未核实 | 先验证登录与目标项目，再核实当前/历史绑定                                           |
| MiSub 用户浏览器 | 当前登录和页面状态未核实                          | 有可用浏览器通道后先核实目标页，不因历史记录重复要求登录                            |
| 业务库/备份      | 脱敏计数、ID 差异及历史完整性未知                 | 按[生产只读取证](production-readonly-evidence.md)分阶段收集，不调用应用 `/api/data` |

“未核实”不表示会话失效。报告只保存计数、必要脱敏 ID、时间和非秘密绑定元数据，不包含订阅 URL、节点、Cookie、密码或完整备份。不读取浏览器凭据文件，不通过可能创建目录的 WebDAV 连接测试试探权限。

## 需要具体目标和批准的操作

| 操作         | 执行前材料与边界                                                                                                                                         |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 持久会话启用 | 按[一次性启用决定](session-activation-decision.md)批准专用会话 D1、schema/收据密钥初始化、绑定、模式切换和强制重新登录；先验证隔离真实 D1 与浏览器       |
| 登录安全启用 | [安全契约](login-security-contract.md)、独立 `MISUB_SECURITY_DB`、schema 和初始 enabled=0 核实；enabled=1 及生产故意锁定独立决定                         |
| 业务事务启用 | 实际权威存储、完整私密副本、所有 writer/在途任务及[迁移验收](subscription-migration-readiness.md)；schema 2、authority/epoch、迁移与模式不随合并自动执行 |
| 数据恢复     | 保留恢复点与新写入处置，在隔离副本演练；生产 restore 是写操作，会话旧快照恢复必须同时使全部旧 SID 失效                                                   |
| Probe 发行   | 固定源码、五平台门槛、来源/许可与公开字节核验；新版本发布和 catalog 切换分别记账，不覆盖 0.2.0                                                           |
| 设备/节点    | 指定设备、服务影响、节点范围、流量和证据字段；真实安装、配对、凭据共享及测速按具体范围授权                                                               |

先完成可审查实现与隔离验证，仅在实际越过上述边界时请求批准。代码/CI、Pages 发布、公开发行字节、真实 D1、用户浏览器、设备与节点分别记账；本地 Chrome/SQLite 不能替代 Cloudflare 响应链、跨 isolate 一致性或 Safari 验收。

每次合并核对准确 HEAD、最新 main、独审及完整 CI，不绕过保护；等前一轮 Pages 发布完成再合并下一项。剩余事项见[未完成清单](open-work-readiness.md)。
